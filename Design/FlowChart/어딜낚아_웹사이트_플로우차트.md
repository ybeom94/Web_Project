# 어딜 낚아 — 웹사이트 플로우차트

> 기준 시안: `메인페이지 시안.png` + `우측 패널 시안.png` (2026-10-26 확정)
>
> 본 문서는 **사용자 화면 이동 및 주요 상호작용**을 정리한 1차 플로우차트다. 화면에 표현되지 않은 세부 기능(내 정보 하위 메뉴, 개별 가이드 페이지 구조 등)은 추후 구현 단계에서 확정한다.

## 1. 전체 사이트 이동 흐름

```mermaid
flowchart TD
    START([사용자 접속]) --> NAV{상단 메뉴 선택}

    NAV -->|홈| HOME[한반도 낚시 포인트 대시보드]
    HOME --> DISCOVER[지역·유형·어종 필터 / 지도 검색·탐색]
    DISCOVER --> SELECT[낚시 포인트 선택]
    SELECT --> DETAIL[우측 고정 상세 패널]
    DETAIL --> WEATHER[날씨·물때]
    DETAIL --> FISH[추천 어종]
    DETAIL --> SPOT[포인트 정보]
    DETAIL --> CATCH[최근 조황]

    NAV -->|어종가이드| SPECIES[어종 목록·검색]
    SPECIES --> SPECIES_INFO[어종 특징과 서식 정보]
    NAV -->|낚시 가이드| GUIDE[초보자 가이드]
    GUIDE --> METHOD[추천 채비·낚시 방법]
    NAV -->|커뮤니티| COMMUNITY[조황·사진·후기 게시판]
    COMMUNITY --> POST[게시글 상세]
    NAV -->|내 정보 아이콘| ME[개인 메뉴 · 세부 기능 추후 정의]

    FISH -. 어종 설명 연결 .-> SPECIES_INFO
    CATCH -. 관련 조황 연결 .-> POST

    classDef primary fill:#D9F6F0,stroke:#21A894,color:#153C55;
    classDef detail fill:#E6F4FF,stroke:#6BB8E6,color:#153C55;
    class HOME,SELECT primary;
    class DETAIL,SPECIES,GUIDE,COMMUNITY detail;
```

## 2. 홈 화면 사용자 상호작용 상세 흐름

```mermaid
flowchart TD
    INIT([홈 접속]) --> READY[한반도 지도 + 좌측 추천 목록 + 우측 기본 선택 포인트 표시]
    READY --> ACTION{사용자 행동}

    ACTION -->|좌측 필터| FILTER[지역 / 낚시 유형 / 대상 어종 드롭다운]
    FILTER --> LIST[추천 목록 갱신 + 페이지네이션]
    LIST --> CARD{추천 카드 조작}
    CARD -->|마우스 오버| CARD_HOVER[지도에서 연결 마커만 강조]
    CARD -->|클릭| PICK[낚시 포인트 선택]

    ACTION -->|지도 검색| SEARCH[지역명 또는 낚시터 검색]
    SEARCH --> SEARCH_KIND{검색 결과}
    SEARCH_KIND -->|지역| MOVE[지도 위치 이동]
    SEARCH_KIND -->|낚시터| PICK

    ACTION -->|중앙 지도| MAP{지도 조작}
    MAP -->|마커 오버| PREVIEW[추천도 + 추천 이유 한 줄 미리보기]
    MAP -->|마커 클릭| PICK
    MAP -->|클러스터 클릭| ZOOM[지도 확대 · 개별 마커 표시]
    MAP -->|레이어·지도 조작| LAYER[낚시 포인트 / 날씨 / 물때 독립 ON·OFF, 확대·축소]

    PICK --> MARK[선택 마커는 파란색 + 원래 추천도 색상 점]
    MARK --> SAFETY{위험 조건 우선 확인}
    SAFETY -->|위험| WARNING[우측 패널에 위험 경고 표시]
    SAFETY -->|일반| SCORE[현재 추천도 표시]
    WARNING --> PANEL[우측 패널 내용 교체 · 현재 탭 유지]
    SCORE --> PANEL

    PANEL --> TAB{우측 탭 선택}
    TAB --> WEATHER[날씨·물때: 날씨 / 풍속 / 파고 / 수온 / 물때 / 추천 시간 / 브리핑]
    TAB --> FISH[추천 어종: 어종별 추천 이유 / 간단한 채비와 방법]
    TAB --> SPOT[포인트 정보: 특징 / 수심·지형 / 현장 공략 팁]
    TAB --> CATCH[최근 조황: 사진 / 후기 / 커뮤니티 연계]

    classDef chosen fill:#D9F6F0,stroke:#21A894,color:#153C55;
    classDef danger fill:#FFF0F2,stroke:#E97582,color:#8D2737;
    classDef panel fill:#E6F4FF,stroke:#6BB8E6,color:#153C55;
    class PICK,MARK chosen;
    class WARNING danger;
    class PANEL panel;
```

## 3. 주요 인터랙션 원칙

| 행동 | 화면 반응 |
|---|---|
| 추천 카드에 마우스 오버 | 해당 지도 마커만 강조, 우측 패널은 유지 |
| 추천 카드 또는 지도 마커 클릭 | 선택 마커 파란색 처리, 원래 추천도는 작은 색상 점으로 유지, 우측 패널 내용 교체 |
| 지도 마커 마우스 오버 | 짧은 정보 카드에 추천도 및 추천 이유 한 줄 표시 |
| 클러스터 클릭 | 해당 영역 확대, 우측 패널 선택은 변경하지 않음 |
| 지도 옵션 | 낚시 포인트 / 날씨 / 물때 세 레이어 독립 ON·OFF |
| 지역·포인트 변경 | 우측 패널의 현재 선택된 탭을 유지하고 콘텐츠만 전환 |
| 위험 조건 감지 | 일반 추천 점수보다 위험도를 우선, 위험 경고를 우측 패널에서 표시 |
| 홈 첫 접속 | 추천 또는 기본 포인트 하나를 선택해 우측 패널을 비우지 않음 |

## 4. 범위 및 확정 수준

- **화면에 보이는 구조 확정:** 상단 4개 메뉴, 좌측 드롭다운 3개와 추천 목록, 중앙 지도, 우측 4개 탭.
- **동작 설계:** 위 인터랙션 원칙은 기존 협의 사항을 반영한 구현 기준.
- **추후 상세 기획:** 어종가이드·낚시 가이드·커뮤니티의 세부 페이지, 계정/즐겨찾기 동작, 실제 API 연결, 데이터 결측 및 갱신 오류 처리.
